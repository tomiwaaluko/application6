Application 6: Real-Time LIDAR Perception System

LidarSafe Technologies | Autonomous Vehicle Prototype

Project Overview

This project demonstrates a real-time embedded system for autonomous vehicle obstacle detection, developed for a Real-Time Systems course. The prototype simulates a LIDAR perception pipeline using an ESP32 microcontroller and FreeRTOS, showcasing critical real-time scheduling and synchronization concepts.

In autonomous vehicles, missing a deadline for obstacle detection could result in a collision. This prototype proves how FreeRTOS ensures predictable timing for safety-critical tasks.

Key Features

  • 5 FreeRTOS Tasks with Rate Monotonic Scheduling (RMS) priorities
  • Emergency ISR with <1ms response time for immediate safety response
  • 3 Synchronization Mechanisms: Mutex, Binary Semaphore, and Queue
  • Real-Time Deadline Compliance with 80%+ timing margin on hard deadlines
  • Distance-Based Obstacle Classification: Collision (<30cm), Proximity (30-100cm), Clear (>100cm)
  • UART Telemetry Logging with timestamped data for determinism proof
  • Visual Warning System with LED indicators (Red: Collision, Yellow: Proximity, Green: Heartbeat)

Real-Time Task Architecture

Hard Real-Time Tasks (Safety-Critical)

HARD SensorTask: 50ms period, Priority 5 - LIDAR sensor polling at 20Hz

HARD ProcessingTask: 100ms period, Priority 4 - Obstacle classification with variable execution time

HARD Emergency_ISR: <1ms response - Immediate emergency stop signal

Soft Real-Time Tasks (Non-Critical)

SOFT WarningTask: 200ms period, Priority 3 - LED warning display

SOFT TelemetryTask: 500ms period, Priority 2 - UART data logging

SOFT HeartbeatTask: 1000ms period, Priority 1 - System alive indicator

CPU Utilization: ~31% (well under 74% RMS schedulability bound)

Technical Stack

Hardware ESP32 DevKit C, HC-SR04 Ultrasonic, 3x LEDs, Emergency Button
RTOS FreeRTOS with preemptive scheduling
Language C++ (Arduino framework)
Platform Wokwi Simulator & PlatformIO
Sync Primitives Mutex, Binary Semaphore, Queue
Testing Logic Analyzer, Serial Timestamps

Learning Outcomes

  • Designed and implemented a Rate Monotonic Scheduled multi-task system
  • Identified and prevented race conditions using appropriate synchronization primitives
  • Analyzed worst-case execution times and verified deadline compliance
  • Balanced design trade-offs between functionality and timing predictability
  • Developed safety-critical embedded software with deterministic timing guarantees
